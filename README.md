# Habit Tracker Frontend 📊

Frontend de una aplicación web para seguimiento de hábitos diarios, diseñada para ayudar a los usuarios a organizar rutinas, monitorear progreso y mantener consistencia en sus objetivos personales.

---

## 🚀 Características

- ✅ Crear hábitos
- ✏️ Editar hábitos
- 🗑️ Eliminar hábitos
- 📅 Seguimiento diario
- 📈 Visualización de progreso
- 🔄 Comunicación con API REST
- 📱 Diseño responsive

---

## 🛠️ Tecnologías utilizadas

- React
- Vite
- JavaScript
- CSS
- Axios
- React Router DOM

## ⚙️ Instalación

Clonar el repositorio:

```bash
git clone https://github.com/JoseRamirezkqa/habittracker-frontend.git
```

Entrar al proyecto:

```bash
cd habittracker-frontend
```

Instalar dependencias:

```bash
npm install
```

---

## ▶️ Ejecución

Iniciar servidor de desarrollo:

```bash
npm run dev
```

La aplicación estará disponible en:

```txt
http://localhost:5173
```
